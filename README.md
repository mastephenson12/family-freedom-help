# The Family Freedom Plan — Help Center

Responsive static help page for Digital Growth Community customers purchasing through The Family Freedom Plan.

## Included
- Searchable help articles and accessible expandable answers
- Product access and technical troubleshooting
- Prominent all-sales-final / no-refunds policy supplied by the site owner
- Support email draft builder (opens the visitor's email client; no server submission)
- Mobile layout and reduced-motion support

Support email: **mark@thefreedomfamilyplan.com**, supplied by the owner. Its domain differs from the main website, **thefamilyfreedomplan.com**. Preserve it unless the owner requests a correction.

## Hosting
Serve `index.html`, `styles.css`, and `help.js` together. No build process or dependencies are needed. Google Fonts is optional; local fallback fonts are defined.

For GitHub Pages, publish the `main` branch at `/ (root)` under repository Settings → Pages. A custom help subdomain can be connected later after DNS is configured. This repository does not modify the main website or its DNS.

## Editing
Update questions and policy text in `index.html`, appearance in `styles.css`, and search/email-draft behavior in `help.js`. Do not add credentials or customer records to this public repository.

No product-specific price, delivery promise, income guarantee, or unverified response-time promise is made. The page is a seller support page, not a claim to operate the Digital Growth Community platform.
